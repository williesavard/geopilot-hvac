# Security policy

## Supported versions

GeoPilot is pre-release software. Security fixes are applied to the latest revision on the `main` branch; no released version is currently supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability, leaked credential, or private household data. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the repository owner privately through their GitHub profile.

Include the affected component, reproduction steps, potential impact, and any suggested mitigation. Remove API keys, network names, addresses, equipment serial numbers, and real telemetry from the report. You should receive an acknowledgement within seven days.

GeoPilot is monitoring software, not a certified safety system. Immediately disconnect prototype hardware that behaves unexpectedly and consult a qualified HVAC or electrical professional when equipment safety may be involved.
