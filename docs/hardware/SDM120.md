# Eastron SDM120

**Status:** Rejected for the current installation
**Scope:** candidate single-phase Modbus energy meter

## Objective

Document the SDM120 candidate for future read-only GeoPilot electrical
measurement.

## Not suitable for this installation

The SDM120 is rated 230 V single phase, line to neutral, range 176 to 276 V. The
target installation, recorded in the untracked local file
`docs/hardware/SITE.md`, is North American 120/240 V split phase. A CT version
wired across L1 and L2 can measure a purely 240 V load, but any 120 V component
is under-read by a single-element meter.

A split-phase capable meter should be selected instead. This document is kept
for traceability of the original candidate.
