## Buying checklist

- [ ] Confirm exact model suffix.
- [ ] Confirm official datasheet.
- [ ] Confirm local electrical certification where relevant.
- [ ] Confirm return policy for bench candidates.
- [ ] Record supplier and purchase date.
- [ ] Photograph labels before installation.
- [ ] Store manuals or stable source URLs in project notes.

## Incoming inspection

- [ ] Model number matches purchase record.
- [ ] Device has expected terminals.
- [ ] Documentation matches the hardware revision.
- [ ] Serial settings can be inspected or configured.
- [ ] No visible damage.
- [ ] Device is not connected to HVAC equipment before bench validation.
