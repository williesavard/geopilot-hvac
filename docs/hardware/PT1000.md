# PT1000

**Status:** Planned
**Scope:** industrial temperature sensing option

## Objective

Compare PT1000 probes against low-cost digital temperature sensors for future
GeoPilot pilot installations.

PT1000 support is not implemented in GeoPilot today.

## Comparison

| Criteria | DS18B20-style digital sensor | PT1000 RTD |
| --- | --- | --- |
| Typical role | Low-cost hobby or light-duty sensing | Industrial temperature measurement |
| Accuracy | TBD by exact part | TBD by class and transmitter |
| Stability | TBD | Generally preferred for industrial use |
| Wiring | Digital bus | RTD wiring to transmitter |
| Cost | Lower | Higher |
| Installation | Simple | Requires probe mounting and transmitter |
| GeoPilot status | Not selected | Planned for Pro/Industrial evaluation |

## PT1000 architecture

```text
PT1000 probe
     |
     v
RTD transmitter
     |
     v
RS485 / Modbus RTU or analog acquisition
```

GeoPilot should read the transmitter output, not implement RTD physics in the
MVP.

## Candidate source reference

Seneca Z-4RTD2 is an official-source candidate for future evaluation because it
is a Modbus RTU RTD input module that lists PT1000 support:

- <https://www.seneca.it/en/linee-di-prodotto/highlights/moduli-io-temperature/z-4rtd2/>

This does not select or approve the device. It only gives GeoPilot a clear
official reference to evaluate against other PT1000 transmitter options.

## Use cases

- loop entering temperature;
- loop leaving temperature;
- pipe-mounted temperature with proper installation;
- permanent pilot measurement where low-cost modules are insufficient.
